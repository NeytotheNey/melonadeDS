# Debug switches (debug builds only)

The full, current list with defaults is the comment block in `app/src/main/cpp/debug/DebugProperties.h`. This file explains the older ones. Compute switches are explained in `HANDOFF-compute.md`, and the GPU discovery ones (`gltimers`, `scenestats`, `hash3d`, `gltrans`, ...) in `docs/plan-gpu-discovery.md`.

Set with `adb shell setprop debug.melonade.<name> <value>` before starting a game; clear with `adb shell "setprop debug.melonade.<name> ''"`. Without adb, type `name=value` pairs into the switch field in Settings → Performance → Diagnostics; they apply at the next game start. The debug log's `Debug switches` line shows what took.

- `threaded2d` 1/0: overrides the threaded 2D setting.
- `hash2d` 1: logs `HASH2D frame=<n> top=<hex> bottom=<hex>` (tag `melonade`) each frame, an FNV-1a over both 2D back buffers. Proves a 2D change is output-identical. At 60 FPS the core's log limit (50 lines a second per call site) drops about 15% of the lines.
- `cpusemu` / `cpus2d`: comma lists of CPU ids to pin the emulator / 2D thread.
- `defercap` 0: turns off deferred display capture (OpenGL). `earlyflush` 0: turns off the early GPU flush.
- `capreads` 1: logs how often games read display capture results and why held capture lines get drawn early (`CAPREADS` and `CAPFLUSH` once a second, sampled `CAPTRACE` and `CAPDIRTY` per frame); see `GPU_CaptureReads.h`.
- `bnohold` (OpenGL/compute): `1`, the debug build default, draws engine B's part of held capture lines right away and holds only engine A's; `0` is the old path. Release builds stay off.
- `hirescap`: `0` off, `1` on (overrides "Upscaled display capture"), `log` adds a once-a-second `HIRESCAP` line, `check` also runs the pass at 1x and compares against native VRAM every 30 passes. See `docs/hires-capture.md`.
- `halfcam` (compute only): frame interpolation for 30 FPS games. `4` is the one to use; `1` camera only, `2` adds characters, `3` adds batch logging, `5` a per-pair trace. See `docs/shelved/frame-interpolation.md`.
- `gpu2dstats` 1: once-a-second `GPU2DSTATS eng=A|B` line counting BG types, sprite features and mid-frame VRAM/palette/OAM changes; fields in `GPU_2DStats.h`.
- `gpu2d` (OpenGL/compute): the GPU 2D shadow renderer. `0` off, `1` only lines that gain something, `all` every eligible line, `check` all plus a 1x readback compared with CPU 2D every 30 frames, `log` adds a once-a-second `GPU2D` line. `gpu2dwide` 1: every layer draws past the screen edge (test only). See `docs/plan-gpu-2d-shadow.md`.
- `widedrops` 1: once-a-second `WIDEDROPS` line on polygons dropped because polygon or vertex RAM was full, and how many the native view had room for. See `docs/plan-widemelon.md`.
- `filter2d` (OpenGL/compute): `0` off, `1` on (overrides "Smooth 2D edges"), `2` only the 2x MMPX pass, `3` all passes with identity output, which must match off. See `docs/plan-gpu-2d.md`. The `FILTER2D` line's `rows` is `filter2drows`, `partial` how many of the frames that ran redrew only some rows, `passrows` the rows each pass drew on average (key / first MMPX pass / second, of 384 / 768 / 1536).
- `filter2drows` (OpenGL and compute, experiment K3 in `docs/plan-gpu-discovery.md`), default 1 in every build since 11-11 (`0` redraws the whole map as before): with filtered 2D, a frame whose keys changed on only some lines redraws only the map rows they can reach (each MMPX pass reads 3 rows up and down, so the changed lines widen by 3 source rows per pass), scissored, without invalidating the targets. `2` checks: every 30th partial redraw, all targets are read back, drawn again in full and compared (`rowchecks` and `rowmismatches` on the `FILTER2D` line, with a `FILTER2D rowcheck mismatch` line for the first few texels). Desktop: `--set Filter2DRows=N` (`--set Filter2DLogging=1` for the line, `--filter2d-mode N` for the other `filter2d` modes).
- `vertexid` 1: once-a-second `VERTEXID sec` line on vertex identity between 3D scenes; 2 adds `VERTEXID scene`. Fields in `GPU3D_VertexId.h`.
- `blitflush` 0 (compute): in frames that hold capture lines, no GPU flush right after the line-192 Blit.
- `lateblit` 0: with threaded 2D on OpenGL/compute, the frame-end 2D barrier and the Blit stay at line 192 instead of just before the line-215 3D render.
- `capspin` 0 (compute): the capture readback sleeps in its map instead of first polling a fence for up to 6000 µs; another value sets that limit (max 20000).
- `gltrans` (OpenGL, experiment T1 in `docs/plan-gpu-discovery.md`), a sum of bits, default 3 in every build (`0` draws as before): `1` skips pass 3's opaque redraw of need-opaque polygons after the clear0 pass, `2` skips need-opaque draws their texture can't pass (CPU scan), `4` (T1c) drops the clear0 pass when the clear alpha is 0 and the GPU has `GL_EXT_shader_framebuffer_fetch`: pass 3's translucent shader reads the color target and doesn't blend over alpha 0. Without the extension (desktop, maybe Mali) `4` changes nothing. A/B it as `gltrans=3` against `7` with `hash3d=1`; with `scenestats=1` the `GLTRANS` line's `fetch_frames` counts the frames drawn that way (out of `clear0_frames`).
- `gledgeskip` (OpenGL, experiment E2 in `docs/plan-gpu-discovery.md`), default 0 (draws as before): `1` leaves out the final pass's edge-marking draw, and the whole final pass with its depth/stencil detach when fog is off too. Exact while edge marking is broken (E1: nothing writes the edge flag, so the edge shader blends `(0, 0, 0, 0)` everywhere); once E1 lands it has to key on whether the frame's polygons can set the flag. A/B it with `hash3d=1` and `gltimers=1` (the `edge` part goes away). Desktop: `--set GLEdgeSkip=1`.
- `glclear` (OpenGL, experiment D1 in `docs/plan-gpu-discovery.md`), a sum of bits, default 0 (draws as before): `1` the plain clear (not the clear bitmap, DISP3DCNT bit 14) is a `glClearBuffer` per target (color, attr, depth/stencil with T1c's 0xBF stencil kept) instead of the full-screen quad, with the same values; `2` invalidates the attr and depth/stencil targets after the frame (`glInvalidateFramebuffer`), since only the color target is read after it. A/B `0` against `3` with `hash3d=1`; `gltimers=1`'s `clear` part shows the cost. Desktop: `--set GLClearFast=N`.
- `compclear` (OpenGL and compute, experiment K2a in `docs/plan-gpu-discovery.md`), default 0 (draws as before): the compositor's main draw starts without the output's old contents, so a tiled GPU needn't load every tile first. `1` clears the whole output to 0 right before that draw, `2` invalidates it (`glInvalidateFramebuffer`) and clears only the padding rows between the screens. The draw covers every other pixel, so both should leave the output the same. Desktop: `--set CompClear=N`.
- `comp1x` (OpenGL and compute, experiment K2c in `docs/plan-gpu-discovery.md`), default 1 in every build since 11-11 (`0` draws as before): a screen with nothing the scale adds (no 3D, no 3D or held wings, no hi-res capture lines) is composited at 1x into the first width x 192 texels of its half of the frame, and the screen shader shows it nearest-upscaled from there. Only while every surface uses the "None" filter with no deband and no Lua tilt-shift (a frame with a screen at 1x that meets another filter, a pre-pass or a tilt-shift, such as one already queued when the filter changes or a paused one, is first expanded into the full frame, so it looks the same), and not in frames with filtered 2D or GPU 2D (`gpu2d`) lines. `1` in a wide view only, where it's pixel-exact; `2` the 256 view too, whose mediump full draw rounds some sub-pixels into the next DS pixel on fp16 GPUs (the RTX 5090 too), so the image changes there (the 1x one is the exact one); `3` checks: the full draw as usual, and every 30 frames the plain screens at 1x into a target of their own, read back and compared, with a `COMP1X mismatch` line for the first few differing pixels. With `scenestats` or `gltimers` on (always in `3`), a `COMP1X` line once a second: frames, how many had only the top / only the bottom / both screens at 1x (in `3`: plain), and why the others couldn't (`front` the frontend, `scale` 1x, `view` the 256 view in mode 1, `nolines`, `filter`, `shadow`), plus the checks. Desktop: `--set Comp1x=N` (`--linear` keeps it off, `--set SceneStats=1` for the line). With filtered 2D (K3), a plain screen is drawn with the filter's program at the filter map's scale instead of 1x and upscaled by the rest (4x at 8x, 12x and 16x; 2x at 4x and 6x with `filter2d=2`), in the 256 view too in `1`, since that program doesn't read its mediump varying there; at scales the map doesn't divide, at the map's own scale, and in `filter2d=3`'s 256 view, both screens are drawn in full (`filter`). The `COMP1X` line's `filtered` counts the frames whose screens were filtered that way, and `3` checks those too.
- `shadowfix` 0 (OpenGL): clear the shadow mask over the whole screen for every mask, instead of per line like software. `maskdepth` 0: depth-equal shadow masks and shadows use plain GL_LESS/GL_LEQUAL, without the DS margin. `equaldepth` 0: the same for all other depth-equal polygons. `shadowlog` 1 (or a frame count): for the first 300 frames, `SHADOWSTATS` and `SHADOWLOG` lines listing masks and shadows.
