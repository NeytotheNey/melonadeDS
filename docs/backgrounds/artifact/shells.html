Handheld shells that fit any panel

Fourteen matte plastic and metal finishes for the area behind the emulated screens. Each file has no fixed size, so the app draws it at the panel's real pixels: the groove stays the same width and the speaker holes stay round whether the Fold is open, closed or on its side.

Settings → Controls → Layouts, open a layout, then ⋮ → Background. Each screen shape in a layout has its own background, so set it on each one.

Use Stretch

In the layout editor, set the background mode to Stretch so the shell fills the whole panel.
